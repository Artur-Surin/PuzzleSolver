# 🧩 Цифровий Пазл (Digital Puzzle Solver in PHP)

Веб-додаток мовою **PHP** для знаходження найдовшого цифрового пазла із 6-значних числоих фрагментів.

---

## 📋 Опис задачі
Дано фрагменти 6-значних чисел. Необхідно скласти найдовший цифровий ланцюжок, де елементами з'єднання є **перші 2 та останні 2 цифри** кожного фрагмента. Кожен фрагмент дозволено використовувати **максимум 1 раз**.

**Приклад:**
Фрагменти: `608017`, `248460`, `177092`  
Рішення: `248460` & `608017` & `177092` $\rightarrow$ `2484(60)80(17)7092`

---

## ⚡ Особливості реалізації
- **Швидкий алгоритм (PHP 8.x)**: Використовує теорію графів (ейлерові степені), попередню оцінку верхньої межі для обрізання гілок (Eulerian Upper-Bound Pruning) та евристику Warnsdorff.
- **Сучасний Glassmorphism UI**: Темний стиль, анімації, підтримка Drag & Drop для `fragments.txt`, візуалізація ланцюжка з підсвічуванням перекриттів.
- **Завантаження та копіювання**: Можливість копіювання результату в 1 клік або завантаження `.txt` файлу.

## 🚀 Як запустити локально (Інструкція для встановлення)

Для запуску потрібен тільки встановлений **PHP** (версії 7.4 або 8.x).

1. **Клонуйте або скачайте папку з проектом**:
   ```bash
   git clone <посилання-на-ваш-репозиторій>
   cd puzzle
   ```

2. **Запустіть вбудований PHP веб-сервер**:
   ```bash
   php -S localhost:8000
   ```

3. **Відкрийте у браузері**:
   Перейдіть за адресою [http://localhost:8000](http://localhost:8000).
